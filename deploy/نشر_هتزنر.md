# 🚀 نشر ZONE X Portal على Hetzner (Ubuntu)

> استبدل في كل مكان:
> - `DOMAIN.COM` → دومينك
> - `SERVER_IP` → IP السيرفر من Hetzner
>
> اللايوت المعتمد:
> - مسار المشروع: `/var/www/ZoneX-Portal`
> - البيئة الافتراضية: `env`  (يعني `/var/www/ZoneX-Portal/env`)
> - السوكِت: `/run/gunicorn.sock`  (نفسه في gunicorn.service و nginx.conf)
> - المستخدم: `root`

---

## الخطوة 0 — السيرفر + الدومين
1. Hetzner Cloud → **Add Server** → **Ubuntu 24.04** → باقة **CX22** → Create → خذ الـ **IP**.
2. من مزوّد الدومين → DNS → سجلّين **A**:
   - `@`   → `SERVER_IP`
   - `www` → `SERVER_IP`
3. انتظر 10–30 دقيقة لانتشار DNS.

---

## الخطوة 1 — تجهيز السيرفر
من ويندوز (PowerShell):
```bash
ssh root@SERVER_IP
```
على السيرفر:
```bash
apt update && apt upgrade -y
apt install -y python3-venv python3-pip postgresql nginx git ufw

ufw allow OpenSSH
ufw allow 'Nginx Full'
ufw --force enable
```

🔑 لتوليد SECRET_KEY (شغّله والبيئة مفعّلة):

## الخطوة 5 — القاعدة والملفات


## الخطوة 6 — Gunicorn كخدمة
```bash
deactivate
cp /var/www/ZoneX-Portal/deploy/gunicorn.service /etc/systemd/system/gunicorn.service
systemctl daemon-reload
systemctl enable --now gunicorn
systemctl status gunicorn      # لازم active (running)
ls -l /run/gunicorn.sock       # لازم السوكِت موجود
```

---

## الخطوة 7 — Nginx
```bash
cp /var/www/ZoneX-Portal/deploy/nginx.conf /etc/nginx/sites-available/zonex
nano /etc/nginx/sites-available/zonex      # غيّر DOMAIN.COM

ln -s /etc/nginx/sites-available/zonex /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t                       # لازم OK
systemctl restart nginx
```
جرّب: `http://DOMAIN.COM` لازم يفتح الموقع.
